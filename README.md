## 🌟 **VISÃO GERAL**

Este projeto é um **clone visual do Spotify**, criado para estudo e prática de desenvolvimento Full Stack.  
Apesar de ser um clone, ele possui **frontend completo em React**, **backend funcional em Node.js** e **MongoDB** como banco de dados.

O foco foi reproduzir a experiência da interface original, com design moderno e comportamento responsivo.

---

## 🎨 **FUNCIONALIDADES DO FRONTEND**

### 🟩 Sidebar profissional  
- Navegação completa  
- Animações e ícones inspirados no Spotify  
- Estado ativo e hover estilizados  

### 🎵 Playlists Dinâmicas  
- Cards renderizados via API  
- Layout fluido e responsivo  
- Efeitos visuais ao passar o mouse  

### ▶️ Player Inferior  
- Botões funcionais  
- Barra de progresso  
- Estilo inspirado no player do Spotify  

---

## 🔌 **BACKEND (Node + Express + MongoDB)**

A API foi estruturada para simular dados reais do Spotify:

✔ Listagem de playlists  
✔ Listagem de músicas  
✔ Modelos no MongoDB  
✔ Rotas organizadas por responsabilidade  
✔ Controllers para lógica de negócio  


---

## ⚛️ **FRONTEND (React + JSX)**

Construído com práticas modernas:

✔ React Hooks (useState, useEffect, useContext)  
✔ Componentização completa  
✔ CSS Modules / Styled Components  
✔ Estrutura organizada por páginas e componentes
